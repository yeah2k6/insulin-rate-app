使用说明

📝 如何记录

每次调整基础率后，在对应时间段填入旧值和新值：

  • 旧值：调整前的数值（如 0.4）
  • 新值：调整后的数值（如 0.45）
  • 有变化的行会自动标橙色
  • 没变化的行，两格填相同数值即可

⌨️ 数值输入技巧

数值输入支持多种格式，自动解析：

  • 0 → 0.0
  • 0.5 或 .5 → 0.5
  • 0.625 → 0.625

⚙️ 设置时间分段

在"设置"页可以自定义时间段：

  • 支持 0:00、1:30、24:00 等格式
  • 自动按开始时间排序

📤 导出与分享

在"历史"页点击卡片可查看详情，支持：

  • 分享给医生（微信/短信等）
  • 复制到剪贴板
  • 在"设置"页可导出全部记录
